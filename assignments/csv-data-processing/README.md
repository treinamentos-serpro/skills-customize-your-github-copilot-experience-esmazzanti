# 📘 Assignment: Working with CSV Data

## 🎯 Objective

Learn how to read, filter, and summarize information stored in CSV files using Python. By the end of this activity, students will be able to work with real-world tabular data without needing additional libraries.

## 📝 Tasks

### 🛠️ Read a CSV File

#### Descrição
Open the provided CSV file and inspect its structure before extracting useful information.

#### Requisitos
O programa concluído deve:

- Read the file using Python's built-in CSV support
- Display the header row and the first 5 records
- Count how many rows are present in the dataset
- Explain which columns are available and what kind of data each one stores

### 🛠️ Filter Data by Criteria

#### Descrição
Write code that filters the dataset based on one or more conditions, such as a department, score threshold, or category.

#### Requisitos
O programa concluído deve:

- Filter records using one column value or a numeric condition
- Show only the matching rows
- Return the number of matching records
- Print a clear message describing the result of the filter

### 🛠️ Create a Summary Report

#### Descrição
Transform the filtered data into a short summary report that helps you understand what the dataset is telling you.

#### Requisitos
O programa concluído deve:

- Compute basic statistics, such as total records, average, minimum, or maximum
- Summarize the data in a readable format
- Store the report in a variable or print it as text
- Highlight at least one useful insight from the data
